# 服務公告：Oxbarrow Payments v1 API 停用

Oxbarrow Payments 將於 2031 年 9 月 30 日停用公開 API 的 v1 版，之後送往 v1 端點的請求都會回傳 HTTP 410。v2 版自 2030 年 1 月起即已推出，提供相同的核心功能，速率限制也維持在每個權杖每分鐘 600 次請求，但身分驗證改為使用 OAuth 2.0 權杖（token），而非靜態 API 金鑰。

根據目前的流量，我們估計約有 1,900 個用戶端應用程式仍在呼叫 v1 端點，其中部分整合如果沒有修改程式碼，可能會無法運作。預計多數團隊需要兩到五個工作天完成移轉，但實際時間可能因金鑰的儲存方式而有所不同。

我們計畫在 2031 年 7 月 1 日與 9 月 1 日寄送提醒郵件，上述時程可能調整，如有更新，會公布在 https://status.example.com/oxbarrow/v1-retirement。如有疑問，可以提交支援工單，類別請選擇 LL-MIGRATE。
