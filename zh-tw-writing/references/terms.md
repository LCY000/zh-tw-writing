# 台灣用語與翻譯參考

寫作或英翻中時，遇到不確定的用詞再來查這份表。`scripts/check_zh.py` 會讀取「直接改用台灣用語」「比對時略過的詞」與「看語意判斷」三個部分，自動找出文件裡的中國用語。一個詞只要台灣有正常用法，就放「看語意判斷」，不要放「直接改用」再靠例外硬撐。表格欄位請保持一致，「例外」欄填的是含有該詞但沒問題的寫法，多個例外用頓號分隔。專有名詞第一次出現的寫法、譯名與「台」「臺」的統一，寫在 SKILL.md 第六節。

## 比對時略過的詞

## 看語意判斷

## 翻譯腔

英翻中最常見的翻譯腔，看到時丟開原句結構，只留意思重新寫。判斷方式是：這句中文能不能很順地倒譯回英文、而且台灣人自己寫時不會這樣說。兩個條件都成立，就是翻譯腔。

| 翻譯腔 | 改寫方向 |
|---|---|
| 對…進行分析／討論 | 直接用動詞：分析…、討論… |
| 通過…來… | 透過…、用…、藉由… |
| …是最…之一 | 只有真的需要強調「之一」時才保留，否則直接描述 |
| 當…的時候 | 多數情況只要「…時」，或直接省略 |
| 被…所… | 改成主動句，或只用「被」 |
| 作為一個…，… | 直接說主語：「身為…」或省略 |
| 在很大程度上 | 大多、主要、相當程度 |
| 使得…成為可能 | 讓…得以、讓…能夠 |
| 存在…的問題 | 有…的問題、…有問題 |
| 做出…決定 | 決定… |
| 一連串的「的」 | 拆成兩句，或改用動詞連接 |
| 用「和」「與」把兩件完整的事接起來（我們檢查了設定和重新啟動了伺服器） | 「和」「與」最適合連接名詞（設定與伺服器），兩邊各是一件完整的事、讀起來不順時，改用逗號、「並」或「再」：我們檢查設定，並重新啟動伺服器。兩個動作做在同一個對象上（檢查與更新設定）、短動詞並列（規劃與執行），以及正式文件用「以及」「及」連接職責或動作（負責審核申請案件，以及追蹤執行進度），都是正常寫法 |
