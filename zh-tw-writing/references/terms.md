## 看語意判斷

這些詞在台灣也有正常用法，不能一律替換，要看在句子裡是什麼意思。檢查腳本只會列出出現次數，提醒你回頭確認。

| 詞 | 這種意思要改 | 這種意思沒問題 |
|---|---|---|
| 文件 | 電腦檔案（file）改成「檔案」 | 書面文件、公文（document） |
| 數據 | 一般的原始資料（data）改成「資料」 | 數據分析、數據顯示、大數據、統計數字 |
| 信息 | 一般資訊改成「資訊」，單一則訊息改成「訊息」 | 幾乎沒有，台灣很少用 |
| 質量 | 品質（quality）改成「品質」 | 物理的質量（mass） |
| 水平 | 程度、能力（level）改成「水準」 | 水平方向（horizontal） |
| 程序 | 電腦程式改成「程式」 | 作業程序、法律程序（procedure） |
| 項目 | 專案（project）改成「專案」 | 條列中的項目、品項（item） |
| 支持 | 技術支援改成「支援」 | 支持某人或某個主張 |
| 通過 | 經由某種方式（via）改成「透過」 | 通過法案、通過考試 |
| 設置 | 軟體設定（settings）改成「設定」 | 設置機構、設置設備 |
| 保存 | 儲存檔案（save）改成「儲存」 | 保存文物、保存期限 |
| 登錄 | 登入帳號（log in）改成「登入」 | 登錄資料、登錄註冊 |
| 代碼 | 程式內容（code）改成「程式碼」 | 股票代碼、錯誤代碼、國家代碼 |
| 默認 | 預設值（default）改成「預設」 | 默許、心照不宣地承認 |
| 用戶 | 軟體或網站的使用者改成「使用者」 | 電信用戶、水電用戶、用戶端 |
| 簡歷 | 求職用的履歷（résumé）改成「履歷」 | 作者簡歷、人物簡介 |
| 智能 | 智慧型裝置、人工智慧改成「智慧」 | 少數已固定的產品名稱 |
| 優化 | 正式文件可考慮改成「改善」「最佳化」 | 台灣已普遍使用，口語文件可保留 |
| 落地 | 計畫實行改成「實施」「推行」 | 落地窗、飛機落地 |
| 獲取 | 可改成「取得」，語氣較自然 | 正式書面語中偶爾使用 |

## 翻譯腔

英翻中最常見的翻譯腔，看到時丟開原句結構，只留意思重新寫。判斷方式是：這句中文能不能很順地倒譯回英文、而且台灣人自己寫時不會這樣說。兩個條件都成立，就是翻譯腔。

| 翻譯腔 | 改寫方向 |
|---|---|
| 對…進行分析／討論 | 直接用動詞：分析…、討論… |
| 通過…來… | 透過…、用…、藉由… |
| …是最…之一 | 只有真的需要強調「之一」時才保留，否則直接描述 |
| 當…的時候 | 多數情況只要「…時」，或直接省略 |
| 被…所… | 改成主動句，或只用「被」 |
| 作為一個…，… | 直接說主語：「身為…」或省略 |
| 在很大程度上 | 大多、主要、相當程度 |
| 使得…成為可能 | 讓…得以、讓…能夠 |
| 存在…的問題 | 有…的問題、…有問題 |
| 做出…決定 | 決定… |
| 一連串的「的」 | 拆成兩句，或改用動詞連接 |
| 用「和」「與」把兩件完整的事接起來（我們檢查了設定和重新啟動了伺服器） | 「和」「與」最適合連接名詞（設定與伺服器），兩邊各是一件完整的事、讀起來不順時，改用逗號、「並」或「再」：我們檢查設定，並重新啟動伺服器。兩個動作做在同一個對象上（檢查與更新設定）、短動詞並列（規劃與執行），以及正式文件用「以及」「及」連接職責或動作（負責審核申請案件，以及追蹤執行進度），都是正常寫法 |
