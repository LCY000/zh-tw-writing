# 翻譯腔與簡轉繁的陷阱

這兩類腳本都查不到，只能靠寫的時候避開、寫完自己對照，所以寫或改任何中文文件前都要先讀這份。翻譯腔是照英文的句型寫中文，簡轉繁的陷阱是一個簡體字對應好幾個繁體字時選錯字。

## 翻譯腔

英翻中最常見的翻譯腔，看到時丟開原句結構，只留意思重新寫。判斷方式是：這句中文能不能很順地倒譯回英文、而且台灣人自己寫時不會這樣說。兩個條件都成立，就是翻譯腔。

翻譯腔不只出現在翻譯，直接寫中文時也常照英文的句型寫，例如介紹文字的第一句只有名詞片語、用「它」當主語、說明類別時加上「一個」。「英文來源」欄寫的是每種翻譯腔照翻的英文句型，同一個句型換了中文說法，也照同樣方向改。

| 翻譯腔 | 英文來源 | 改寫方向 |
|---|---|---|
| 對…進行分析／討論 | conduct an analysis of、carry out a discussion of、perform an evaluation of，名詞化的動作配上空泛動詞 | 直接用動詞：分析…、討論… |
| 通過…來… | through…、by doing… | 透過…、用…、藉由… |
| …是最…之一 | one of the most… | 只有真的需要強調「之一」時才保留，否則直接描述 |
| 當…的時候 | when…、while… | 多數情況只要「…時」，或直接省略 |
| 被…所… | 被動語態（is affected by…、was discovered by…） | 改成主動句，或只用「被」 |
| 作為一個…，… | As a…、… | 直接說主語：「身為…」或省略 |
| 在很大程度上 | to a large extent、largely | 大多、主要、相當程度 |
| 使得…成為可能 | make … possible、enable … to | 讓…得以、讓…能夠 |
| 存在…的問題 | there is a problem with…、there exist… | 有…的問題、…有問題 |
| 做出…決定 | make a decision | 決定… |
| 一連串的「的」 | 名詞前疊好幾層修飾，或 of 片語連用（the impact of the policy of the government） | 拆成兩句，或改用動詞連接 |
| 用「和」「與」把兩件完整的事接起來（我們檢查了設定和重新啟動了伺服器） | and 連接兩個動詞片語或子句（We checked the settings and restarted the server） | 「和」「與」最適合連接名詞（設定與伺服器），兩邊各是一件完整的事、讀起來不順時，改用逗號、「並」或「再」：我們檢查設定，並重新啟動伺服器。兩個動作做在同一個對象上（檢查與更新設定）、短動詞並列（規劃與執行），以及正式文件用「以及」「及」連接職責或動作（負責審核申請案件，以及追蹤執行進度），都是正常寫法 |
| 開頭只有名詞片語、沒有動詞（一個中文寫作 skill，讓 AI 寫出的報告……） | 名詞後面接 that 子句（A skill that makes AI…），或用逗號接補充說明（A skill, designed to…），常見於專案簡介與產品介紹的第一句 | 補上主語和「是」：「zh-tw-writing 是用來優化中文寫作方面的 skill，讓 AI……」。標題、表格欄位、圖說本來就是名詞片語，不用改 |
| 它專注在……、它負責……、它提供……（「它」指工具或產品，放在句子開頭） | 事物當主語接動作動詞（It focuses on…、It provides…、The tool handles…），英文常這樣寫 | 中文很少用「它」指工具或產品當句子開頭。直接講範圍或功能（「處理中文寫作與改寫」）、用名稱當主語（「zh-tw-writing 處理……」「系統提供匯出功能」），或省略主語 |
| 是一個……（X 是一個開源的排版工具） | 冠詞 a、an 照翻（X is an open-source typesetting tool） | 說明身分或類別時不用量詞：「X 是開源的排版工具」。真的在講數量時（只有一個例外、開一個帳號）照常用 |

## 簡轉繁的陷阱

一個簡體字對應好幾個繁體字，要看意思選字。簡轉繁工具常選錯，AI 直接寫繁體字時也會犯同樣的錯，例如「幹淨」「頭發」「回復訊息」。這些要看語意判斷，腳本不檢查，寫完或轉換完要自己對照。

| 簡體 | 繁體要依意思分開 |
|---|---|
| 干 | 乾（乾燥、乾淨）、幹（幹部、樹幹）、干（干擾、相干） |
| 后 | 後（之後、後面）、后（皇后） |
| 里 | 裡（裡面）、里（公里、鄰里） |
| 发 | 發（發送、發展）、髮（頭髮、理髮） |
| 只 | 只（只有）、隻（一隻） |
| 台 | 台（台灣、平台）、臺（正式文件的臺灣）、颱（颱風）、檯（櫃檯） |
| 系 | 系（系統、科系）、係（關係）、繫（聯繫） |
| 面 | 面（面對、表面）、麵（麵條） |
| 云 | 云（人云亦云）、雲（雲端） |
| 制 | 制（制度、限制）、製（製造、製作） |
| 复 | 復（恢復、復原）、複（複製、重複）、覆（回覆、覆蓋） |
| 历 | 歷（歷史、經歷）、曆（日曆、行事曆） |
| 钟 | 鐘（時鐘、鐘聲）、鍾（鍾情、姓鍾） |
| 尽 | 盡（盡力、用盡）、儘（儘管、儘快） |
| 冲 | 沖（沖水）、衝（衝突、衝刺） |
| 划 | 划（划船、划算）、劃（規劃、劃分） |
| 别 | 別（分別、別人）、彆（彆扭） |
| 准 | 准（准許、批准）、準（準備、標準） |
| 范 | 范（姓范）、範（範圍、範例） |
| 余 | 余（姓余）、餘（剩餘、其餘） |
| 征 | 征（出征）、徵（徵才、特徵） |
| 获 | 獲（獲得）、穫（收穫） |
| 汇 | 匯（匯款、匯出）、彙（彙整、詞彙） |
| 并 | 並（並且、並列）、併（合併、兼併） |
| 松 | 松（松樹）、鬆（放鬆、鬆散） |
| 板 | 板（木板、主機板）、闆（老闆） |
| 表 | 表（表格、表示）、錶（手錶） |
| 斗 | 斗（北斗、漏斗）、鬥（戰鬥、鬥爭） |
| 游 | 游（游泳、上游）、遊（旅遊、遊戲） |
| 了 | 了（完了、了解）、瞭（一目瞭然），「了解」「瞭解」台灣都通用，全文統一即可 |
| 采 | 采（風采、神采）、採（採用、採購） |
| 卷 | 卷（試卷、卷宗）、捲（捲動、捲入） |
| 克 | 克（克服、公克）、剋（相剋） |
